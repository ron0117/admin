# fix-bug - 修复 Bug

分析并修复项目中的 Bug。

## 触发条件

用户报告 Bug 或需要修复问题时，例如：
- "这个功能不工作了"
- "点击按钮没有反应"
- "帮我修复这个错误"

## 修复流程

### 1. 理解问题
- 询问或确认 Bug 的表现
- 确认复现步骤
- 查看错误日志/截图

### 2. 定位问题
- 读取相关代码文件
- 检查数据类型和边界条件
- 查看权限配置是否正确
- 检查 API 调用是否成功

### 3. 常见问题检查
| 问题类型 | 检查点 |
|---------|-------|
| 页面不显示 | 路由配置、权限配置、组件导入 |
| 按钮不显示 | 权限类型（read/write）、按钮权限配置 |
| 数据不加载 | API 调用、响应格式、错误处理 |
| 样式错乱 | UnoCSS 类名、scoped 样式冲突 |
| 类型错误 | TypeScript 类型定义、props 类型 |

### 4. 修复规范
- 修改前必须读取受影响文件
- 多文件变更使用 Plan 模式
- 修复后验证相关功能
- 不引入新的 `console.log`

### 5. 提交规范
```
fix(模块): 问题描述

- 问题原因
- 修复方案

Co-Authored-By: Claude Opus 4.6
```

## 输出

1. Bug 原因分析
2. 修复方案说明
3. 修改的代码
4. 验证建议
