# 请求处理使用说明

## 核心功能

1. **简化错误对象**：默认返回 `{code, msg, statusCode, url, method}`，而不是完整的 AxiosError
2. **错误码多语言文案**：内置按语言（`zh-cn/zh-tw/en-us`）映射错误码到提示文案
3. **避免重复提示**：自动避免错误消息重复显示
4. **统一 API**：直接在 config 中配置，无需额外函数
5. **可捕获错误**：支持在发生错误时直接 `throw`，业务层可用 `try/catch` 获取后端错误体（AxiosError 的 `response.data`）

## 基础使用

```typescript
// 1. 最简单的使用（封装好的 API 函数）
const { data, error } = await fetchGetGameList();
if (error) {
  // error 是简化后的对象: { code, msg, statusCode, url, method }
  console.log(error.code);  // '1001'
  console.log(error.msg);   // 错误消息
  return;
}

// 2. 直接使用 request
const { data, error } = await request({
  url: '/api/game/list',
  method: 'GET'
});
```

## 错误码多语言文案（推荐）

项目内置的错误码文案在：

- `src/locales/langs/error-message/index.ts`

按语言分别维护（`error_message_cn / error_message_tw / error_message_us`），请求发生后端业务错误时会自动根据当前语言展示对应文案。

## 自定义错误处理

```typescript
const { data, error } = await request({
  url: '/api/game/delete',
  method: 'DELETE',
  params: { id },
  customConfig: {
    onError: ({ code, msg }) => {
      if (code === '1005') {
        // 特殊处理
        window.$messageBox?.confirm(msg, '警告');
      } else {
        window.$message?.error(msg);
      }
    }
  }
});
```

## 业务层 try/catch 捕获错误

> 适用于：你希望拿到后端返回的错误体，并在页面里做自定义处理

```typescript
import { requestThrow } from '@/service/request';

try {
  const data = await requestThrow({ url: '/api/game/list', method: 'GET' });
  console.log(data);
} catch (e: any) {
  // 当前实现：throw AxiosError
  console.log(e.response?.data); // 后端返回的错误体（如果有）
  console.log(e.response?.data?.code); // 后端错误码（如有）
  console.log(e.response?.data?.message || e.message); // 错误消息
}
```

## 直接使用 request + throwOnError

```typescript
try {
  const { data } = await request({
    url: '/api/game/list',
    method: 'GET',
    customConfig: {
      throwOnError: true
    }
  });
  console.log(data);
} catch (e: any) {
  console.log(e.response?.data);
}
```


## 不显示错误消息

```typescript
const { data, error } = await request({
  url: '/api/test',
  method: 'GET',
  customConfig: {
    showErrorMsg: false  // 不自动显示，手动处理
  }
});
```

## 获取完整 AxiosError

```typescript
const { data, error } = await request({
  url: '/api/debug',
  method: 'GET',
  customConfig: {
    simplifyError: false  // 返回完整的 AxiosError 对象
  }
});
```

## 配置说明

```typescript
interface CustomRequestConfig {
  showErrorMsg?: boolean;      // 是否显示错误消息 (默认: true)
  simplifyError?: boolean;     // 是否简化错误对象 (默认: true)
  throwOnError?: boolean;      // 是否在发生错误时直接 throw (默认: false)
  onError?: (error: { code: string; msg: string }) => void;  // 自定义错误处理
}

interface SimplifiedError {
  code: string;         // 错误码
  msg: string;          // 错误消息
  raw?: unknown;        // 后端返回的错误体（如果有，非必要，优先用 msg）
  statusCode?: number;  // HTTP状态码
  url?: string;         // 请求URL
  method?: string;      // 请求方法
}
```
