# 修复 Bug

## 流程

1. **理解**：表现、复现步骤、日志/截图
2. **定位**：相关文件、类型/边界、API、路由
3. **常见检查**

| 类型 | 检查点 |
|------|--------|
| 页面不显示 | 路由、elegant 生成、组件导入、登录态 |
| 菜单为空 / 全 403 | privilege stub 是否半删（guard/菜单/PageMenu 须一致） |
| 数据不加载 | API、响应格式、mock/env |
| 样式错乱 | UnoCSS、scoped |
| 类型错误 | TS / props |

4. **规范**：改前 Read；多文件先对齐计划；无新 `console.log`
5. **提交**：仅用户要求时提交；格式 `fix(模块): 简述`

## 输出

原因分析、方案、改动说明、验证建议（可对照 `docs/test/`）
