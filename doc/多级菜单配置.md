# 多级菜单配置

对应文件：`src/components/custom/page-menu.vue`
组件名：`PageMenu`


## 核心功能

1. **自动生成树状Tabs**：根据创建页面的目录自动生成三级或者四级的菜单
2. **根据配置文件排序**：直接在 config 中配置，无需额外函数
3. **用WeakMap缓存页面**：用`WeakMap`缓存已经渲染的页面内容

## 基础用法

在二级菜单中的写法：

```vue
<!-- PageMenu已注册为全局组件 -->
<template>
  <PageMenu />
</template>
```

三级菜单的要在对应的文件夹下面创建menu.vue，脚本会读取menu.vue作为页面的子节点
对应配置的`config.ts`中可以配置**同级菜单排序**和**菜单名称**（支持国际化）

## 示例：`src/views/test` 目录树

```text
src/views/test
├─ menu1
│  └─ index.vue
└─ menu2
   ├─ index.vue
   ├─ tab1
   │  ├─ config.ts
   │  └─ menu.vue
   ├─ tab2
   │  ├─ config.ts
   │  └─ menu.vue
   └─ tab3
      ├─ config.ts
      ├─ child1
      │  ├─ config.ts
      │  └─ menu.vue
      └─ child2
         ├─ config.ts
         └─ menu.vue
```
