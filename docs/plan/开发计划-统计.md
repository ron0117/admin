# 开发计划 · 积分统计

> 对齐：[需求-统计-梳理版](../detail/需求-统计-梳理版.md)、[技术设计-统计.md](../design/技术设计-统计.md)  
> Nest 细项：[nestjs/docs/plan/开发计划-统计.md](../../../nestjs/docs/plan/开发计划-统计.md)  
> MVP：Must UC-01～09 + Should（未知 `menuCode` 单独成行）  
> 粗估：**1.5～2.5 人天**（Nest 0.5～1 + Admin 1～1.5）  
> **须用户再说「按计划开发」后才写业务代码**

跨项目：前缀 **N** = `nestjs/`，**A** = `admin/`。命令在对应项目根执行。

---

## 1. 里程碑

| 里程碑 | 目标 | 建议耗时 | 完成标志 |
|--------|------|----------|----------|
| M0 Nest 聚合 | 汇总 + 用户分页，口径与单测对齐设计 | 0.5～1d | `point-stats.service.spec.ts` 绿；Swagger 可见两个 GET |
| M1 统计页 | 筛选、三图、三表、路由文案 | 0.7～1d | 侧栏「积分统计」可开；改时间三块一起变 |
| M2 首页 | 欢迎大卡片换成同一套三图 | 0.2～0.3d | 首页近 30 天与统计页默认数字一致 |
| M3 收尾 | typecheck、对照 AC | 0.1～0.2d | Admin `pnpm typecheck` 过 |

**依赖：** M0 → M1 → M2 → M3。图组件在 M1 写好，M2 只引用，不复制一套 option。

**不可打乱：** 不在前端把流水列表再加总；不改 `PointLedger` 表；不改 `request/shared.ts`。

Won't（导出、充值/调账/余额图、规格下钻、标题跳转、Electron）不进本计划。Could「首页标题链到统计页」不做。

## 2. 任务拆分（可勾选）

### M0 · Nest（UC-02～05、09，AC-01～05）

细项以 Nest 计划 P0～P2 为准，本文件只记完成门：

- [x] N0.1 `GET /admin/points/stats`、`GET /admin/points/stats/users` 按设计返回
- [x] N0.2 单测覆盖：只计已完成消费、多角色整笔、未分配、Top 10 与分页前 10 一致、非法时间 400
- [x] N0.3 无 migrate、无新索引

### M1 · 积分统计页（UC-01～06、08）

- [x] A1.1 `utils/time.ts` 增加 `getShanghaiRecentDaysRange`（`dayjs.tz()`，上海自然日）
- [x] A1.2 `service/api/points.ts` + `typings/api/points.d.ts`：`fetchPointStats`、`fetchPointStatsUsers`
- [x] A1.3 `views/points/stats/modules/`：`UserConsumeBar`、`RoleConsumeBar`、`FeatureConsumePie`（`useEcharts`）
- [x] A1.4 `views/points/stats/index.vue`：预设近 7/30/90/全部/自定义；上图下表；用户表分页搜索
- [x] A1.5 功能占比前端计算，最后一行补差到 100%；`total === 0` 显示 `0%` 和空态文案
- [x] A1.6 角色卡说明「按当前绑定，多名角色会重复计入」；角色表无占比列
- [x] A1.7 elegant `points_stats`（`order: 3`，`mdi:chart-bar`）+ `route` / `page.points.stats` 三语
- [x] A1.8 自定义止日早于起日不发请求

### M2 · 首页（UC-07、08，Q-06）

- [x] A2.1 `views/home/index.vue` 保留 `HeaderBanner`，去掉 `ContentInfo`
- [x] A2.2 第一行用户柱 14 / 角色柱 10，第二行功能环 12；窄屏堆叠
- [x] A2.3 进入时用近 30 天调汇总；副标题「近 30 天净消耗」；失败三卡都显示失败
- [x] A2.4 图只从 `views/points/stats/modules` 引用

### M3 · 收尾

- [ ] A3.1 `pnpm typecheck`；无 `console.log`；不改 `request/shared.ts`
- [ ] A3.2 对照 [自测方案-统计](../test/自测方案-统计.md) 勾 TC-API / TC-UI / TC-HOME / TC-ENG
- [x] A3.3 `admin/docs/memory/执行日志-统计.md` 留到实现时再写

### 不在本计划

- 导出、Electron、充值/调账/余额分布、按规格或按天拆、首页跳转、改流水表、新图表库

```text
N0 聚合接口 + 单测
  → A1 统计页（含图组件）

          → A3 typecheck
```
