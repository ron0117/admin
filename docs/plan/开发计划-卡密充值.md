# 开发计划 · 卡密充值

> 对齐：[需求梳理版](../detail/需求-卡密充值-梳理版.md)、[技术设计](../design/技术设计-卡密充值.md)  
> Nest 细项：[nestjs/docs/plan/开发计划-卡密充值.md](../../../nestjs/docs/plan/开发计划-卡密充值.md)  
> Electron 细项：[electron/docs/plan/开发计划-卡密充值.md](../../../electron/docs/plan/开发计划-卡密充值.md)  
> MVP：Must UC-01～03、05～12  
> 粗估：**3～5 人天**（Nest 1.5～2 + Admin 1～1.5 + Electron 0.5～1 + 联调 0.5）  
> **须用户再说「按计划开发」后才写业务代码**

跨项目：前缀 **N** = `nestjs/`，**A** = `admin/`，**E** = `electron/`。命令在对应项目根执行。

**已实现（不重复计工）：** Electron 账号 section、店铺窗（`RECHARGE_CARD_SHOP_URL`）、Ping++ 档位 UI 关闭。

---

## 1. 里程碑

| 里程碑 | 目标 | 建议耗时 | 完成标志 |
|--------|------|----------|----------|
| M0 Nest 卡密 | 表 + 生成/列表/兑换 API | 1～1.5d | migrate；Admin 可调 generate；桌面 redeem 入账 |
| M1 Admin 卡密管理 | 列表、生成、筛选、导出 | 1～1.5d | typecheck；hideInMenu Ping++ 菜单 |
| M2 Electron 兑换 | IPC + 账号页输入兑换 | 0.5～1d | 有效卡密积分变；无效提示 |
| M3 收尾 | AC + 回归 | 0.5d | points hold e2e 仍绿；自测方案走通 |

**依赖：** M0 →（M1 ∥ M2）→ M3。M1 列表页依赖 M0 generate/list；M2 仅依赖 M0 redeem。

**不可打乱：** 兑换入账逻辑 **仅在 Nest 事务**；Electron/Admin 不得本地改积分。

Won't：作废卡密、wzyp API、Ping++ 扩展、独立「兑换记录」菜单（用筛选代替）。

## 2. 任务拆分（可勾选）

### M0 · Nest（NU-01～07、09）

- [ ] N0.1 Prisma：`RechargeCard`、`RechargeCardStatus`；`User` / `AdminUser` relation
- [ ] N0.2 migrate + `.env.example`（`RECHARGE_CARD_BATCH_MAX` 等）
- [ ] N0.3 `RechargeCardsService`：码生成、normalize、批量 insert
- [ ] N0.4 `POST /admin/recharge-cards/generate`
- [ ] N0.5 `GET /admin/recharge-cards` 分页筛选 + user join
- [ ] N0.6 `GET /admin/recharge-cards/export` CSV（上限 10000）
- [ ] N0.7 `POST /recharge/cards/redeem` + 事务 + `PointLedger.recharge`
- [ ] N0.8 `RechargeErrorCode.RECHARGE_CARD_INVALID`；兑换 `@Throttle`
- [ ] N0.9 e2e：generate → redeem → 二次 redeem 失败；并发同码

### M1 · Admin（UC-01～05、11）

- [ ] A1.1 elegant：`points_rechargecards` + 视图文件
- [ ] A1.2 i18n：卡密管理、列、状态、生成表单
- [ ] A1.3 `points_rechargepackages` / `points_rechargerecords` → `hideInMenu: true`
- [ ] A1.4 `service/api/recharge.ts`：generate、list、export
- [ ] A1.5 `views/points/recharge/cards`：JQDataTable + 生成弹窗 + 筛选
- [ ] A1.6 导出 CSV（blob 下载）
- [ ] A1.7 `pnpm typecheck`

### M2 · Electron（EU-02～04；EU-01 已有）

- [ ] E2.1 `recharge-api-client.redeemCard`
- [ ] E2.2 `recharge-runtime.rechargeRedeemCard` + refresh points
- [ ] E2.3 IPC `RechargeRedeemCard` + preload + `docs/IPC.md`
- [ ] E2.4 账号页：卡密输入 + 兑换 + 文案更新
- [ ] E2.5 `npm run typecheck`

### M3 · 收尾

- [ ] T3.1 手工：生成 5 张 → Admin 明文可见 → 桌面兑 1 张 → 状态已兑换
- [ ] T3.2 手工：导出 CSV 与列表一致
- [ ] T3.3 对照 [自测方案](../test/自测方案-卡密充值.md)（下一步文档）

### 不在本计划

- Ping++ 新功能、卡密作废、用户兑换历史页、库内哈希-only 存储
