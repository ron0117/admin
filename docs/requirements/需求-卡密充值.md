# 需求 · 卡密充值（Admin）

> 协作：[nestjs/docs/requirements/需求-卡密充值.md](../../../nestjs/docs/requirements/需求-卡密充值.md)、[electron/docs/requirements/需求-卡密充值.md](../../../electron/docs/requirements/需求-卡密充值.md)

1. 在「积分管理」下新增或扩展 **卡密管理**（与现有充值管理并列或替代 Ping++ 档位运营入口，以梳理版为准）：运营可 **批量生成卡密**，生成时 **自由填写到账积分**（正整数）。
2. 卡密列表：展示 **完整卡密**、到账积分、**状态**、生成时间、兑换时间、兑换用户（账号）等；支持分页与筛选（状态、时间、积分、卡密关键字）。
3. 状态（本期）：**未兑换**、**已兑换**。卡密 **导出给外部店铺（如 wzyp）售卖**，系统 **不跟踪「已出售」**；「未出售」产品语义对应 **未兑换**（含已导出但未在织序核销）。
4. 支持 **导出** 卡密（CSV/Excel，供店铺上架）；导出行为不改变状态，仅审计可选。
5. 样式与交互参考现有表格页（`JQDataTable` 等）；需 **Admin 菜单权限**（与充值记录等积分模块一致，若现有充值管理已挂菜单则对齐）。
6. **充值记录** 页可扩展或新增 **卡密兑换记录** 视图：账号、卡密、到账积分、兑换时间（数据来自 Nest 流水/卡密表）。
7. Ping++ 应用内支付档位 **本期不再扩展**；运营主路径改为卡密。
