# 需求 · 后台登录（与 Electron JWT 隔离）

后台登录与桌面端（Electron）必须使用**不同的 JWT**，互不能冒用。

锁定方案：

- 独立接口：`POST/GET /admin/auth/login|refresh|me|logout`
- 独立密钥：`JWT_ADMIN_SECRET`（必须与 `JWT_SECRET` 不同）
- access payload 带 `aud=admin`
- 后台 refresh 哈希加 `admin:` 前缀，与桌面端 refresh 不能互换
- 仅 `role=admin` 且 `status=active` 可后台登录
- `/admin/users*` 只接受后台 JWT；桌面端 JWT → 401
- 后台 JWT 不能调桌面端 `/auth/me`、`/tasks` 等 → 401

不改 Prisma 表。产品文档以 `admin/docs` 为准。

> **后续修订：** 登录主体改为独立 `AdminUser` 表，不再使用 `User.role=admin`。见 [需求-管理员管理.md](./需求-管理员管理.md)。
