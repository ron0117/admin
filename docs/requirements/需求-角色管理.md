# 需求 · 角色管理

为 Electron 桌面端做**菜单权限**：后台配角色与菜单，用户可绑多个角色；桌面端按权限显示菜单。后台管理员登录权限仍 stub 全通，不在本期。

## 已锁定

| 项 | 结论 |
|----|------|
| 管理对象 | Electron `User` 的业务角色；**不是** `AdminUser`，也不是旧 `User.role` 枚举 |
| 菜单目录 | Nest 建菜单表（种子，后台不做「菜单管理」CRUD） |
| 本期菜单 | 只做 **生图** 树：父级「生图」+ 现有子菜单；勾父级 = 拥有该节点及全部子菜单（含日后新增子节点） |
| 关系 | 角色 1:N 菜单；用户 N:N 角色；权限取**并集** |
| 后台页面 | 角色增删改查；角色配置页勾选菜单树；用户列表/表单可配多个角色 |
| 桌面端 | 本期接入：按 `/auth/me` 权限隐藏生图顶栏与子导航；无权限可登录，看不到生图 |
| 删除 | 角色**禁用**不物理删；有用户绑定时不可删（禁即可） |
| 空角色 | 用户可登录；工作台等未入库菜单仍可见；生图整棵不可见 |
| 旧字段 | `User.role`（`user\|admin`）列暂留，UI/API 不再使用 |
| 后台 RBAC | 仍 stub 全通 |
| 文档位置 | 只放 `admin/docs` |

## 生图菜单树（Must，与现网导航对齐）

- 生图（父）
  - 创作：灵感创作、去同质化裂变、原景出新、自由创作、live图生成、文案仿写
  - 管理：历史任务、磁盘清理

工作台 / 抖店 / 设置本期不入库，桌面端仍全员可见。

## 后台（Must）

- **角色管理**：分页列表（名称、状态、创建时间）；新建/编辑名称与备注；启用/禁用
- **角色配置**：对指定角色勾选菜单树（父级勾选=全开，也可只勾部分子菜单）
- **用户列表**：展示已绑角色；创建/编辑可多选角色

## 服务器（Must）

- 菜单表 + 角色表 + 角色-菜单 + 用户-角色
- 种子写入上表生图树
- 管理端 API（后台 JWT）：角色 CRUD、给角色设菜单、给用户设角色、查菜单树
- 桌面端 `/auth/me`（或等价）返回该用户并集后的菜单码，供 Electron 裁剪导航

## 桌面端（Must）

- 登录/拉 me 后按菜单码隐藏：无父级且无任一子级 → 隐藏「生图」顶栏
- 有部分子级 → 显示生图，仅显示已授权子项
- 无权限直达生图 URL → 回到工作台（或等价无权限落地），不展示内容

## 明确不做

- 后台自身菜单/按钮 RBAC
- 菜单管理页、按钮级权限、数据权限
- 物理删除角色/菜单；导出
- 把旧 `User.role=admin` 当业务角色
- 改 Admin 全局 `{code,data}` 请求封装
