# 需求梳理版 · 框架

> 源需求：[需求-框架.md](../requirements/需求-框架.md)  
> 状态：可评审 / 可排期  
> 结论摘要：从 `o2o-backoffice` 抽出可复用后台框架空壳；保留路由规则、框架组件与接口约定；删除业务域与 privilege 运行时依赖（改为 stub 或移除）。

---

## 1. 产品定位

| 项 | 说明 |
|----|------|
| 产品 | 可二次开发的中后台前端框架模板（本仓 `admin`） |
| 来源 | `D:\项目\o2o\code\o2o-backoffice`（Soybean Admin ELP / Vue3+Vite7+Element Plus 二次定制） |
| 不做什么 | 不保留 O2O 业务页、不保留真实权限体系、不绑定原项目内网后端作为模板默认依赖 |
| 成功标准 | `pnpm i && pnpm dev` 可启动；登录壳 + 布局 + 路由/多标签可用；无业务域与 privilege 配置树残留 |

---

## 2. 用户与用例

| ID | 角色 | 用例 | 优先级 | 验收要点 |
|----|------|------|--------|----------|
| UC-01 | 模板维护者 | 从指定源仓搬运脚手架与 packages | Must | 目标仓可安装依赖；无 `node_modules`/`dist`/`_apis` 巨文件误拷 |
| UC-02 | 二次开发者 | 按文件约定新增页面并自动进路由/菜单 | Must | elegant-router 规则可用；`pnpm gen-route` 可生成 |
| UC-03 | 二次开发者 | 使用框架组件（表单/搜索/表格/PageMenu 等）搭页 | Must | `JQ*` 等约定组件可导入；至少 1 个示例页可演示 |
| UC-04 | 二次开发者 | 使用统一请求封装调接口 | Must | `service/request` 可用；成功码/鉴权头/过期处理约定保留 |
| UC-05 | 二次开发者 | 无 privilege 时仍可完整浏览菜单与页面 | Must | 菜单不过滤；路由 guard 仅校验登录（或开发态可跳过）；无 403 误拦 |
| UC-06 | 二次开发者 | 删除/不出现 O2O 业务模块 | Must | views 无 member/game/cash/system/announce/bo 等业务域 |
| UC-07 | 模板使用者 | 本地冒烟：登录壳 → 首页 → 布局交互 | Must | 主题/多标签/侧栏等壳能力可用（可 mock 登录） |
| UC-08 | 模板维护者 | 品牌与环境可改名 | Should | 应用标题、env 前缀、仓库名与 O2O 脱钩 |
| UC-09 | 二次开发者 | 可选接入真实后端登录 | Should | 登录适配点文档化或可配置；默认不依赖内网 |
| UC-10 | 模板维护者 | 裁剪重型依赖 | Could | 图表/编辑器等非框架必需依赖可后置裁剪 |

## 3. 功能拆解

### 3.1 必须保留（框架）

| 模块 | 范围 | 备注 |
|------|------|------|
| 工程脚手架 | 根配置、Vite、UnoCSS、TS、eslint、pnpm workspace | 含 `packages/@sa/*` |
| 布局壳 | layouts、多标签、主题、面包屑 | |
| 路由规则 | `router/**`、elegant-router 插件、文件路由约定 | guard 需去掉 privilege 段 |
| PageMenu 机制 | 组件 + 「子目录 config.ts + menu.vue」约定 | **机制保留，业务内容删除** |
| 框架组件 | common/advanced；custom 中表单/表格/搜索/对话框/导入导出等 | 业务专用控件（如 member-input）默认不迁或改示例 |
| 请求层 | `@sa/axios` + `service/request`（及现有 alova 骨架若无成本可留） | 去掉业务 API 文件 |
| 状态骨架 | app / route / tab / theme / auth（精简） | 去掉 role / batch 等业务向 store |
| 登录与异常壳 | `_builtin` login / 403 / 404 / 500；精简 home | |
| 类型与 i18n 骨架 | 框架相关 typings、公共 locales | 删除业务文案 |

### 3.2 必须删除 / 改造

| 类别 | 动作 |
|------|------|
| 业务 views | 删除 `bo` / `member` / `game` / `cash` / `system` / `announce` / `user-center` 等 |
| 业务 API | 删除对应 `service/api`；保留 auth/route/upload 骨架或 mock |
| swagger 生成物 | 不拷贝 `src/_apis`；去掉或占位 `openAi*` 脚本 |
| privilege 配置 | 删除 `roleConfig.ts`、`constants/privilege`、`PRIV.*`、bo/role 管理页 |
| privilege 运行时 | `judgePrivilege` / `hasMenuPrivilege` / 菜单过滤 / PageMenu 过滤 / `v-auth` → **stub 恒通过或注销** |
| 业务常量枚举 | 删除 O2O 语义 constants/enum |
| 发布绑定 | azure-pipelines / 原 docker 上传脚本等默认不作为模板必带（可另议） |

### 3.3 privilege 处理原则（重要）

| 原则 | 说明 |
|------|------|
| 禁止半删 | 不得只删配置树而留守卫过滤，避免菜单空白/全 403 |
| 推荐 stub | 框架侧统一「全通」；指令可 stub 或移除注册 |
| 可选扩展 | 后续若需权限，作为可插拔能力另开需求，不在本需求范围 |

## 4. 非功能需求

| ID | 类型 | 要求 |
|----|------|------|
| NFR-01 | 可运行 | Node ≥ 20.19、pnpm ≥ 8.7；`dev`/`typecheck` 可通过（允许先收敛错误） |
| NFR-02 | 可维护 | 目录边界清晰：框架 vs 示例 vs 未来业务 |
| NFR-03 | 可移植 | 无私有 npm；默认不依赖原内网 IP |
| NFR-04 | 文档 | README 说明：如何加页、如何用请求封装、权限已关闭 |
| NFR-05 | 体积 | MVP 不强制裁依赖；Should 阶段可裁 |

---

## 5. 端到端流程（目标态）

```text
安装依赖 → 启动 dev
  → 打开登录页（mock / 开发旁路 / 可配置真实接口）
  → 进入布局壳 + 首页
  → 侧栏可见框架/示例菜单（无 privilege 裁剪）
  → 打开示例页（含可选 PageMenu 演示）
  → 多标签 / 主题切换正常
```

## 6. 范围 In / Out

| In（本需求） | Out（明确不做） |
|--------------|-----------------|
| 从 `code/o2o-backoffice` 搬运并清洗为模板 | 从 `code_component` 整仓搬运（仅必要时文件级对照） |
| 保留路由规则、框架组件、请求等框架接口 | 保留 O2O 业务功能与权限管理 UI |
| privilege 运行时 stub / 移除 | 实现新的 RBAC/ABAC 权限方案 |
| 可本地冒烟的最小示例 | 对接生产环境、发布流水线迁移 |
| 品牌/环境与 O2O 脱钩（Should） | 大规模依赖裁剪与性能专项（Could） |

## 9. 验收标准

| ID | 标准 | 对应 |
|----|------|------|
| AC-01 | 目标仓存在可安装的 monorepo（含必要 `packages/@sa/*`） | UC-01 |
| AC-02 | `pnpm dev` 能打开应用；布局壳可见 | UC-07 |
| AC-03 | 无业务域目录与业务 API；无 `roleConfig` / `PRIV` 配置树 | UC-06 |
| AC-04 | 路由/菜单不因 privilege 为空而不可用 | UC-05 |
| AC-05 | 文件约定新增路由可用（或文档说明 gen-route） | UC-02 |
| AC-06 | 框架请求封装与至少一组约定组件可在示例中使用 | UC-03/04 |
| AC-07 | README 写清：保留能力、已删除内容、如何加页 | NFR-04 |

## 10. 风险摘要（梳理级）

| 风险 | 等级 | 对策方向 |
|------|------|----------|
| privilege 横切导致空壳不可用 | 高 | 统一 stub，禁止半删 |
| 登录绑内网 | 高 | mock/旁路；env 去内网默认 |
| 业务常量/组件渗入框架 | 中 | 清单化删除；耦合控件不迁 |
| 依赖过重 | 中 | MVP 先可跑，Could 再裁 |
