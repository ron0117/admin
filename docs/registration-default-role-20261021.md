# 新注册用户默认角色

配套服务端：ron0117/nestjs 分支 `work/video-proxy-default-role-20261021`。

“用户 → 角色管理”新增“注册默认角色”列和“设为注册默认”操作。当前默认角色显示“新用户默认”，不能直接停用；先切换其他启用角色即可停用旧角色。

更改默认值只影响后续新注册用户，已有用户角色保持不变。修改角色菜单权限仍使用现有的“配置菜单”功能。

依赖服务端角色列表返回 `isRegistrationDefault`，以及管理员接口 `PUT /admin/roles/:id/registration-default`。先部署服务端并执行默认角色迁移，再发布本后台版本。

验证：生产构建和 vue-tsc 类型检查通过。未改动主分支、线上配置及用户数据。
