# 技术设计 · 框架

> 对齐：[需求-框架-梳理版](../detail/需求-框架-梳理版.md)  
> 源仓：`D:\项目\o2o\code\o2o-backoffice`  
> 目标仓：`d:\模板\admin`  
> 待澄清默认：Q-01 mock+旁路；Q-02 stub 指令；Q-03 home+1 演示页；Q-04 业务控件不迁；Q-05 不带 CI/docker；Q-06 暂用 `admin`

---

## 1. 目标与约束

| 项 | 内容 |
|----|------|
| 目标 | 将 O2O Backoffice 清洗为可二次开发的中后台框架模板：可安装、可启动、无业务域、无真实 privilege |
| 技术基座 | Soybean Admin ELP（`@sa/elp` 1.3.15）：Vue 3.5 + Vite 7 + TS + Element Plus + UnoCSS + Pinia + elegant-router |
| 约束 | 无私有 npm；默认不依赖原内网后端；privilege **禁止半删**；本阶段不实现新权限方案 |
| 非目标 | 生产发布流水线、完整 RBAC、业务功能迁移 |

---

## 2. 总体架构

```text
admin/                          # 目标模板仓
├── packages/@sa/*              # axios/alova/hooks/materials/utils/color/ofetch/scripts/uno-preset
├── build/                      # Vite 插件（含 elegant-router）
├── src/
│   ├── layouts/                # 布局壳
│   ├── router/                 # 路由 + guard（去 privilege）
│   ├── store/                  # app/route/tab/theme/auth（精简）
│   ├── service/request/        # 请求封装（框架接口）
│   ├── service/api/            # 仅 auth/route/upload 骨架 + mock
│   ├── components/             # 框架组件 + PageMenu
│   ├── hooks/                  # common + business/role(stub)
│   ├── directives/             # v-auth / v-hie → stub
│   ├── views/_builtin|home|demo  # 壳 + 示例
│   └── plugins|theme|styles|locales|typings
├── .env*                       # 去内网默认；mock/旁路开关
└── docs/                       # 本流水线文档
```

**分层职责：**

| 层 | 职责 | 二次开发接触面 |
|----|------|----------------|
| 工程层 | pnpm workspace、Vite、Uno、eslint | 改 env / 脚本 |
| 壳层 | layouts、主题、多标签、i18n | 少改 |
| 路由层 | 文件约定 → elegant-router → 菜单 | **高频**：加 `views/**` |
| 组件层 | JQ* / PageMenu / common | **高频** |
| 请求层 | `createFlatRequest` + api 模块 | **高频** |
| 权限层（模板态） | stub 全通 | 默认不改；未来可插拔另开需求 |

## 3. 模块职责与改造策略

### 3.1 搬运策略

| 步骤 | 动作 |
|------|------|
| 1 | 从源仓复制（排除 `node_modules` `dist` `.temp` `src/_apis` 及业务 secrets） |
| 2 | 覆盖/落入目标仓；改 `package.json` name、应用标题相关 env |
| 3 | 按下方清单删业务、stub privilege、加 demo、改登录 |
| 4 | `pnpm i` → `pnpm gen-route`（如需）→ `pnpm dev` / `typecheck` |

不带入：`azure-pipelines*`、`docker/`、原 `upload.sh`（Q-05）。

### 3.2 保留模块

| 模块 | 路径 | 说明 |
|------|------|------|
| Workspace 包 | `packages/*` | 原样保留 |
| 路由插件 | `build/plugins/router.ts` | layouts 绑定、path transform |
| 布局 | `src/layouts/**` | |
| 路由核心 | `src/router/**` | guard 需改 |
| 请求 | `src/service/request/**`、`service-alova/**`（可选留） | |
| 框架组件导出 | `src/components/index.ts` | 见 §5 |
| PageMenu | `src/components/custom/page-menu.vue` | 去掉 privilege 过滤 |
| common/advanced | `src/components/common|advanced` | |
| 状态 | `app` `route` `tab` `theme` `auth` | auth 精简 privileges |
| 登录壳 | `views/_builtin/**`、精简 `views/home/**` | |
| hooks/common | `src/hooks/common/**` | |

### 3.3 删除模块

| 类别 | 路径/范围 |
|------|-----------|
| 业务 views | `views/{announce,bo,cash,game,member,system,user-center}` |
| 业务 API | 见 §5.2 删除列 |
| privilege 配置 | `src/roleConfig.ts`、`src/constants/privilege/**` |
| role 仓 | `src/store/modules/role/**`、`utils/privilege-tree-sort.ts`、相关 `constants/role` `enum/role` |
| 业务常量 | O2O 语义 `constants/{business,game,member,cash,...}`、对应 enum |
| 业务控件 | `member-input.vue`、`game-category-select.vue` 等（Q-04） |
| swagger | 不拷贝 `_apis`；去掉/占位 `openAi*` 脚本 |
| 业务 locales | `locales` 中业务页文案 |

### 3.4 Privilege Stub（必做，对齐 UC-05 / AC-04）

| 文件 | 改造 |
|------|------|
| `src/hooks/business/role.ts` | `judgePrivilege` / `hasMenuPrivilege` → 恒 `true`；层级判断恒通过或简化 |
| `src/router/guard/route.ts` | 去掉/旁路 `hasMenuPrivilege` 拦截；保留登录态校验 |
| `src/store/modules/route/shared.ts` | `filterAuthRoutesByRoles` 改为不过滤或恒保留 |
| `src/components/custom/page-menu.vue` | 去掉按 privilege 过滤 Tab |
| `src/directives/auth.ts` / `hie.ts` | stub：不隐藏 DOM（Q-02） |
| `src/store/modules/auth/**` | 可清空 `privileges` 依赖；`isStaticSuper` 可保留作旁路 |
| 删除 | `roleConfig.ts`、`PRIV`、role store、bo 权限管理页 |

**禁止：** 只删配置树而保留过滤逻辑。

### 3.5 登录（对齐 Q-01 / UC-07 / UC-09）

| 模式 | 行为 | 默认 |
|------|------|------|
| Mock | 登录不调内网；写入假 token + 假用户；`fetchUserInfoByToken` 走本地 | **MVP 默认** |
| 开发旁路 | 可用 `VITE_STATIC_SUPER_ROLE=Y` 等现有开关辅助 | 启用 |
| 真实后端 | 保留 `auth.ts` 请求形状；`VITE_SERVICE_BASE_URL` 可配置 | 可选文档说明 |

相关 API 骨架（保留形状，实现可 mock）：

| 函数 | 原 URL |
|------|--------|
| `fetchLogin` | `POST /public/bo/auth/login` |
| `fetchUserInfoByToken` | `GET /gate/bo/user/me` |
| `fetchRefreshToken` | `POST /auth/refreshToken` |

Env 关键项：`VITE_SERVICE_*`、`VITE_AUTH_ROUTE_MODE=static`、`VITE_ROUTE_HOME`、`VITE_HTTP_PROXY`、`VITE_SERVICE_MOCK*`；去掉内网 IP 默认值。

### 3.6 示例页（Q-03）

| 页面 | 作用 | 验收 |
|------|------|------|
| `views/home/**` | 登录后落地 | AC-02 |
| `views/demo/**`（新建） | 演示 PageMenu + 至少一种 JQ*（如 JQSearch/JQDataTable 静态数据） | AC-06 |

演示页不得依赖已删业务 API。

## 4. 关键流程

### 4.1 启动与鉴权（模板态）

```text
main → 插件/指令(stub) → router
  → 未登录：constant 路由（login）
  → 登录：mock 写 token → 拉用户信息(mock) → 初始化静态路由（不过滤 privilege）
  → 进入 VITE_ROUTE_HOME → 布局壳
```

### 4.2 加页（二次开发主路径）

```text
新增 views/foo/index.vue（+ 可选 i18n）
  → pnpm gen-route（或 dev 热生成）
  → elegant 更新 routes/imports
  → 菜单自动出现（无 privilege 裁剪）
```

PageMenu 深层级：

```text
views/foo/bar/config.ts + menu.vue + 子页
  → PageMenu 渲染 Tab（不过滤 privilege）
```

### 4.3 请求

```text
页面/API 模块 → service/request（createFlatRequest）
  → 成功码 VITE_SERVICE_SUCCESS_CODE
  → Authorization / logout / expired 码处理
  → 业务禁止直连 axios（约定保留）
```

## 5. 接口与约定（框架接口）

### 5.1 路由约定

| 约定 | 说明 |
|------|------|
| 文件路由 | `views/**/index.vue` → elegant-router |
| meta | `title` `i18nKey` `constant` `keepAlive` `order` `hideInMenu` `icon` `multiTab` 等 |
| 布局 | `base` / `blank` ← `build/plugins/router.ts` |
| 生成命令 | `pnpm gen-route`（`sa gen-route`） |
| 生成物 | `src/router/elegant/{routes,imports,transform}.ts`、`typings/elegant-router.d.ts` |

### 5.2 API 模块

| 文件 | 策略 |
|------|------|
| `auth.ts` `route.ts` `upload.ts` `index.ts` | **保留骨架**（auth 可 mock） |
| `announce-*` `bo-*` `cash-*` `game-*` `member*` `system-*` | **删除** |

### 5.3 组件导出（保留）

| 导出名 | 源 |
|--------|-----|
| `JQForm` / `FormItem` / `TFormProps` | `custom/form.vue` |
| `JQSearch` | `custom/search.vue` |
| `JQDataTable` | `custom/data-table.vue` |
| `JQDialogForm` | `custom/dialog-form.vue` |
| `JQDropdown` | `custom/drop-down.vue` |
| `JQCustomPage` | `custom/custom-page.vue` |
| `JQBatchProgressDialog` | `custom/batch-progress-dialog.vue` |
| PageMenu（`JQPageMenu`） | `custom/page-menu.vue`（改 stub） |

另：`unplugin-vue-components` 自动注册继续保留。

### 5.4 权限「接口」（模板态）

| API | 模板行为 |
|-----|----------|
| `judgePrivilege(path, type?)` | 恒 true |
| `hasMenuPrivilege(path)` | 恒 true |
| `v-auth` / `v-hie` | 不拦截展示 |
| `PRIV.*` / `roleConfig` | **不存在** |

文档需声明：当前无真实权限；勿依赖 stub 行为做安全边界。

## 7. 技术选型与备选

| 决策 | 选择 | 备选 | 理由 |
|------|------|------|------|
| 搬运源 | `code/o2o-backoffice` | `code_component` | 更新、约定更完整 |
| UI/基座 | 保持 Soybean ELP + Element Plus | 换 Ant Design Vue 等 | 成本低、与源一致 |
| 去权限 | stub 全通 | 硬删所有调用点 | 调用面大；stub 更稳 |
| 登录 | mock + 旁路 | 仅真实 API | 可移植、可冒烟 |
| 示例 | home + demo | 仅 home | 覆盖 UC-03/AC-06 |

## 8. 风险与对策

| 风险 | 等级 | 对策 | 追溯 |
|------|------|------|------|
| privilege 半删导致菜单空/403 | 高 | §3.4 清单一次性改完 | UC-05 AC-04 |
| 内网 env 残留 | 高 | 清洗 `.env*`；mock 默认 | NFR-03 UC-07 |
| 删业务后类型/i18n/路由生成物报错 | 中 | 删后 `gen-route`；收敛 locales/typings | AC-01/02 |
| 框架组件间接依赖业务 API | 中 | 不迁耦合控件；demo 用静态数据 | Q-04 AC-06 |
| typecheck 历史债务 | 中 | MVP 以 dev 可跑优先；typecheck 尽量清零 | NFR-01 |
| 依赖过重 | 低（本阶段） | Could 再裁 | UC-10 |
