## 2. 环境与前置

| 项 | 要求 |
|----|------|
| Node | ≥ 20.19 |
| 包管理 | pnpm ≥ 8.7 |
| 命令 | 在仓库根执行 `pnpm i`、`pnpm dev`；需要时 `pnpm gen-route`、`pnpm typecheck` |
| 配置 | `.env*` 无原内网默认；mock/旁路可用（Q-01） |
| 浏览器 | Chromium 系最新稳定版即可 |
| 前置完成 | 开发计划 M0～M3 任务已勾选；M4 README 至少草稿可用于 TC-DOC |

## 5. 通过 / 失败标准

| 结果 | 标准 |
|------|------|
| **通过** | 所有 Must 用例期望满足；AC-01～07 均可勾选 |
| **有条件通过** | Must 通过，但 TC-QLT-01/02 或 Should（品牌、指令样例）未完成，且已写入已知问题 |
| **失败** | 任一 Must 失败：无法安装/启动、菜单空或 privilege 403、业务目录残留、`roleConfig`/`PRIV` 仍在、demo 无框架组件、README 缺失关键说明 |

缺陷记录建议字段：用例 ID、现象、复现步骤、关联文件、阻塞级别（Blocker/Major/Minor）。

## 6. 回归要点

以下变更后须重跑对应集：

| 变更 | 回归 |
|------|------|
| 改 guard / route filter / `useRole` / PageMenu | TC-RT-01/02/05 |
| 改登录/auth store/env | TC-BOOT-02/03/04 |
| 增删 views 或 gen-route | TC-RT-03、菜单目视 |
| 改 `components/index` 或 JQ* | TC-UI-03 |
| 改 README | TC-DOC-01/02 |

冒烟最小集（日常）：`TC-BOOT-01` → `TC-BOOT-03` → `TC-RT-01` → `TC-RT-05` → `TC-UI-01`。
