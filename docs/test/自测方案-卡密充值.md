## 1. 测试范围

| 纳入 | 不纳入 |
|------|--------|
| Admin 卡密生成、列表、筛选、明文展示 | Ping++ 档位/订单新功能 |
| Admin 导出 CSV（Should） | wzyp 店铺内支付流程 |
| Admin 侧栏：卡密管理可见；充值管理/记录隐藏 | 卡密作废 |
| Electron 店铺窗 + 卡密兑换 + 积分刷新 | 用户兑换历史页 |
| Nest 兑换入账、`recharge` 流水 | 库内只存哈希 |

---

## 2. 环境与前置

| 项 | 要求 |
|----|------|
| Nest | `prisma migrate` 含 `RechargeCard`；`nest-api` 运行中 |
| Admin | 后台 JWT 可登录；具备卡密管理菜单权限 |
| Electron | 测试用户已登录；`.env` 可选配 `RECHARGE_CARD_SHOP_URL` 测店铺窗 |
| 测试数据 | Admin 生成至少 3 张卡密（如 100 积分 ×2、200 积分 ×1） |
| 积分基线 | 记录桌面用户兑换前 `points` |

**通过：** §3 期望全部满足。**失败：** 客户端本地改积分、同一卡密双入账、未兑换却显示已兑换。

## 3. 用例表

### 3.1 Admin · 卡密管理

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-ADM-01 | 打开「卡密管理」 | 分页列表；侧栏 **无**（或隐藏）Ping++「充值管理/充值记录」 | UC-01 设计 hideInMenu |
| TC-ADM-02 | 生成：数量 5、积分 100、备注「自测批次」 | 成功提示；列表新增 5 条 **未兑换**；卡密为完整明文 | UC-01 AC-01 |
| TC-ADM-03 | 筛选状态=未兑换 | 仅 unused | UC-03 |
| TC-ADM-04 | 筛选生成时间为今天 | 仅今日生成 | UC-03 |
| TC-ADM-05 | 输入某卡密片段关键字 | 列表缩小到匹配行 | UC-03 Should |
| TC-ADM-06 | 生成数量 501 或积分 0 | 前端或接口拒绝 | 设计 batchMax |
| TC-ADM-07 | 无 token 调 generate/list | 401 | UC-11 |

### 3.2 Admin · 导出（Should）

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-ADM-08 | 当前筛选下点「导出 CSV」 | 下载文件；列含卡密、积分、状态；行数与筛选一致 | UC-04 |

### 3.3 Admin · 兑换后对账

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-ADM-09 | 桌面兑换 1 张 100 积分卡密后刷新列表 | 该卡 **已兑换**；兑换时间、测试用户账号有值 | UC-05 AC-02 |
| TC-ADM-10 | 筛选状态=已兑换 | 含刚兑换行；未兑换卡不在内 | UC-05 AC-04 |
| TC-ADM-11 | 积分流水 type=充值 | 有一条 recharge，积分 +100 | UC-05 Should |

### 3.4 Electron · 店铺与兑换

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-EL-01 | 账号页点「前往店铺购买」 | 打开店铺窗（已配 URL）或禁用提示（未配） | UC-06 |
| TC-EL-02 | 输入有效未兑换卡密点「兑换」 | 成功 toast；输入清空；积分 +N | UC-07 AC-02 |
| TC-EL-03 | 再次输入同一卡密兑换 | 失败提示「无效或已使用」；积分不变 | UC-08 AC-03 |
| TC-EL-04 | 空卡密点兑换 | 前端提示，不请求 | EU-02 |
| TC-EL-05 | 错误/随机卡密 | 失败提示；积分不变 | UC-08 |
| TC-EL-06 | 点「刷新积分」 | 与 Nest `/auth/me` 一致 | — |
| TC-EL-07 | 侧栏无 Ping++ 档位按钮 | 仅卡密区块 | UC-07 卡密路径 |

## 4. 通过标准

- §3 全部 **Must** 用例（TC-ADM-01～07、09～10、TC-EL-02～05、07，TC-REG-01～03）达到期望。
- **Should**（TC-ADM-08、11）不通过记为待办，不挡 MVP 时可文档标注。
- 出现 **同一卡密双入账**、**兑换失败却加积分** 任一条，整项不通过。
