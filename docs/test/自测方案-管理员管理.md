## 1. 测试范围

| 纳入 | 不纳入 |
|------|--------|
| `AdminUser` 迁移、`/admin/auth` 换表、`/admin/admins*`、seed | 物理删除、导出、RBAC、自动迁移存量 `User.role=admin` |
| 管理员管理页；用户管理去角色 | mock 列表（UC-15） |
| Electron JWT 401；仅 User 不能后台登录；仅 AdminUser 不能 Electron 登录 | Access 黑名单（禁用后 access 短窗口，接受） |
| 禁自己 / 最后管理员；无 passwordHash | 改 `shared.ts`、新 privilege 树 |

## 2. 环境与前置

| 项 | 要求 |
|----|------|
| Nest | `npx prisma migrate deploy` 已含管理员表；**重新** `npx prisma db seed` |
| Seed | `ADMIN_SEED_EMAIL` / `ADMIN_SEED_PASSWORD` 写入 **AdminUser**（不是 `User.role=admin`） |
| Admin | `VITE_AUTH_MOCK=N`、`VITE_NEST_BASE_URL` 或 `/proxy-nest` |
| 对照账号 | ① 仅 Electron `User` ② 仅 `AdminUser` ③ 两表同邮箱不同密码（可选） |
| Swagger | `http://localhost:3000/docs` tag `admin-auth` / `admin-admins` / `admin-users` |

**接口速查**

| 能力 | 方法 | Path |
|------|------|------|
| 后台登录 | POST | `/admin/auth/login` |
| 后台刷新 / me / 登出 | POST/GET | `/admin/auth/refresh` `/admin/auth/me` `/admin/auth/logout` |
| 管理员列表/创建 | GET/POST | `/admin/admins` |
| 管理员更新/重置 | PATCH/POST | `/admin/admins/:id` `/admin/admins/:id/reset-password` |
| Electron 用户 | GET/POST/PATCH | `/admin/users` …（无 role） |
| 桌面端登录 | POST | `/auth/login` |

## 4. 通过 / 失败

| 结论 | 条件 |
|------|------|
| **通过** | Must 用例均过；e2e 绿；typecheck 过；未改 `shared.ts` |
| **失败** | 种子无法后台登录；Electron 用户能进后台；管理员能进 Electron（无对应 User 时）；可禁自己/最后管理员；用户管理仍能设 role；响应含 hash |

禁用后 1h 内旧 access 仍可能可用：记为已知限制，不挡通过。

---

## 5. 回归要点

- `/auth/register|login|refresh` 与 tasks 行为不变
- 后台 JWT 仍不能调 `/tasks`、`/auth/me`
- 用户管理创建/启停/重置密码（Electron）仍可用
- 改角色相关旧用例 **作废**，勿再测 `User.role=admin` 升权
