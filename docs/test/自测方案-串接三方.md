# 自测方案 · 串接三方（Ping++ 充值）

> 对齐：[需求梳理版](../detail/需求-串接三方-梳理版.md)、[技术设计](../design/技术设计-串接三方.md)、[开发计划](../plan/开发计划-串接三方.md)  
> 范围：MVP（UC-01～14 / AC-01～07）  
> Nest e2e 见 [nestjs 自测方案](../../../nestjs/docs/test/自测方案-串接三方.md)  
> Ping++ Test 环境：**先完成** [Ping++-Test-控制台配置清单](../../../nestjs/docs/Ping++-Test-控制台配置清单.md)

---

## 1. 测试范围

| 纳入 | 不纳入 |
|------|--------|
| Admin 充值档位 CRUD、上下架、排序 | 导出、限购、改价审计 |
| Admin 充值记录：账号远程搜、时间、金额列 | 退款原路 |
| Electron 账号导航、WebView、轮询、积分刷新 | 用户端充值历史页 |
| Webhook 入账、`recharge` 流水 | Live 生产多渠道切换 Runbook |

---

## 2. 环境与前置

| 项 | 要求 |
|----|------|
| Nest | migrate；`PINGPP_*` Test 按 [配置清单](../../../nestjs/docs/Ping++-Test-控制台配置清单.md)；Webhook 公网 HTTPS 或 dev 隧道；Mock 可不配 Key |
| Admin | 后台 JWT 可登录；侧栏见「积分管理」下充值管理/充值记录 |
| Electron | 本需求包；测试用户已登录；Nest 至少 1 个**已上架**档位 |
| 测试账号 | 建议专用 Electron 用户，便于在 Admin 按 keyword 搜到 |
| 积分基线 | 记录充值前 `points`，便于对比 |

**通过：** 用例期望全部满足。**失败：** 未 Webhook 入账却本地加积分、双入账、下架档仍可下单、顶栏一点即退出（回归）。

---

## 3. 用例表

### 3.1 Admin · 充值管理

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-ADM-01 | 打开充值管理 | 列表可 CRUD；列含金额、基础/赠送积分、上架、排序 | UC-01 AC-01 |
| TC-ADM-02 | 新建档位：100 元、80 基础 + 20 赠送，上架 sort=1 | 保存成功；列表可见合计 100 积分 | UC-02 |
| TC-ADM-03 | 下架该档位 | 状态为下架 | UC-02 |
| TC-ADM-04 | 桌面刷新账号页档位列表 | 下架档不出现 | UC-02 AC-01 |
| TC-ADM-05 | 重新上架 | 桌面再次出现 | UC-02 |

### 3.2 Admin · 充值记录

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-ADM-06 | 完成一笔桌面充值（见 TC-EL）后打开充值记录 | 有对应行：账号、充值额度、手续费、实际到账、到账积分、状态 paid、时间 | UC-03 AC-02 |
| TC-ADM-07 | 账号筛：输入测试用户 email 片段 | 远程下拉可选；选中后列表仅该用户 | UC-04 |
| TC-ADM-08 | 选今天时间范围 | 仅范围内订单 | UC-05 |
| TC-ADM-09 | 无 token 访问 `/admin/recharge-orders` | 401 | UC-13 |

### 3.3 Electron · 账号与导航

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-EL-01 | 看侧栏顺序 | 「账号」在「设置」之后 | EU-01 |
| TC-EL-02 | 已登录点击顶栏用户区 | 进入账号页，**不**退出 | UC-06 AC-03 |
| TC-EL-03 | 账号页点退出 | 回登录页 | UC-10 |
| TC-EL-04 | 未登录访问 `/account/main/home` | 重定向登录 | EU-10 |

### 3.4 Electron · 充值与轮询

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-EL-05 | 账号页查看积分与档位 | 与 Nest 一致；赠送文案可见 | UC-07 |
| TC-EL-06 | 选档位点充值 | 弹出 WebView；**支付完成前**顶栏积分不变 | UC-08 AC-04 |
| TC-EL-07 | Ping++ Test 完成支付（或控制台模拟成功） | Webhook 后轮询到 paid；WebView 关闭；积分 +100（按档位）；toast 成功 | UC-09 AC-05 |
| TC-EL-08 | 关 WebView 且未支付 | 积分不变；可再发起新单 | EU-07 |
| TC-EL-09 | 同一笔重复 Webhook（或 e2e 模拟） | 积分只加一次 | UC-11 |

### 3.5 订单超时（可与 Nest 联测）

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-ORD-01 | 创建订单不支付，等待超过 TTL（或改短 env 测） | 状态 closed；之后补 Webhook 仍不加积分 | UC-12 AC-06 |

### 3.6 回归 · 积分消费

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-REG-01 | 任一生图页 hold → 生成 → commit/refund 各一次 | 与充值上线前一致 | AC-07 |
| TC-REG-02 | Admin 功能设置、积分流水、用户调账 | 仍可用 | — |
| TC-REG-03 | Admin `pnpm typecheck` | 通过 | 计划 A2.7 |

## 4. 通过标准

- §3 全部用例达到期望。
- 出现 **WebView 加载完成即加积分**、**重复入账**、**closed 后入账** 任一条，整项不通过。
