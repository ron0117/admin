# 自测方案 · 积分模块

> 对齐：[需求-积分模块-梳理版](../detail/需求-积分模块-梳理版.md)、[技术设计-积分模块.md](../design/技术设计-积分模块.md)、[开发计划-积分模块.md](../plan/开发计划-积分模块.md)  
> 范围：MVP（UC-01～16）  
> Nest e2e 与本表互补：自动化过不等于可免 Admin / Electron 人工联调

---

## 1. 测试范围

| 纳入 | 不纳入 |
|------|--------|
| 功能设置 6 行 + 修改弹窗；流水筛选；用户调账 | 支付充值、邀请、导出、用户端流水 |
| hold/commit/refund、幂等、TTL、me.points | 历史/磁盘清理扣费 |
| Electron CTA、不足拦截、失败退还、双击两笔 | 旧桌面包兼容 |
| 后台 JWT vs 桌面 JWT 隔离 | 改 `shared.ts`、新 privilege 树 |

---

## 2. 环境与前置

| 项 | 要求 |
|----|------|
| Nest | migrate + **重新 seed**；`POINTS_HOLD_TTL_SEC` 联调 TTL 可临时改为 60 |
| Admin | `VITE_AUTH_MOCK=N`；种子管理员登录 |
| Electron | 指向同一 Nest 的**本需求改过的包** |
| 账号 | ① AdminUser 运营 ② Electron 用户（后台 +100 积分） ③ 余额 0 用户 |
| Swagger | `http://localhost:3000/docs` tag `points` / `admin-points` / `admin-users` / `auth` |

**接口速查**

| 能力 | 方法 | Path |
|------|------|------|
| 功能设置 | GET/PATCH | `/admin/point-features` `/admin/point-features/:menuCode` |
| 流水 | GET | `/admin/point-ledgers` |
| 调账 | POST | `/admin/users/:id/points` |
| 配置（桌面） | GET | `/point-features` |
| 扣费 | POST | `/points/hold` `/points/commit` `/points/refund` |
| 会话 | GET | `/auth/me`（`user.points`） |

## 3. 用例表

### 3.1 工程

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-ENG-01 | 搜 Admin `request/shared.ts` 本需求 diff | 无业务改动 | NFR-05 AC-09 |
| TC-ENG-02 | 无新 PRIV 树 | stub 全通 | AC-09 |
| TC-ENG-03 | Admin `pnpm typecheck`；Nest `test:e2e` | 通过 | 计划 A2.6 N1.8 |
| TC-ENG-04 | Electron `docs/IPC.md` 含 points 通道 | 已写 | E3.1 |

### 3.2 功能设置与调账

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-SET-01 | 打开功能设置 | 6 行创作；无历史/清理 | UC-01 AC-01 |
| TC-SET-02 | 改 live 优/中/良与备注保存 | 列表摘要与备注回显 | UC-02 |
| TC-SET-03 | 单价填 -1 | 弹窗校验不提交 | UC-02 |
| TC-ADJ-01 | 用户列表见积分列；+100 | 余额 100；流水调增 | UC-04/05 |
| TC-ADJ-02 | 余额 10 调减 20 | 失败提示；余额仍 10 | UC-05 Q-04 |
| TC-LED-01 | 流水按用户/类型/时间筛选 | 能找到调增与后续消费 | UC-03 AC-02 |

### 3.3 鉴权

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-AUTH-01 | 无 token GET `/admin/point-features` | 401 | UC-15 |
| TC-AUTH-02 | 桌面 JWT PATCH 功能设置 | 401 | AC-08 |
| TC-AUTH-03 | 后台 JWT POST `/points/hold` | 401 | AC-08 |

### 3.4 桌面扣费

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-EL-01 | 登录后顶栏积分 = me.points | 与后台列表一致 | UC-06 AC-04 |
| TC-EL-02 | 灵感 CTA | `开始创作 · n 积分`，n=单价×张数 | UC-07 |
| TC-EL-03 | live 切换优/中/良 | CTA 总价跟随后台三档 | UC-07 |
| TC-EL-04 | 余额 0 点生成 | toast 不足；无新任务/无流水消费成功 | UC-08 AC-05 |
| TC-EL-05 | 余额够，点一次成功 | 余额减少；流水一条已完成消费 | UC-09 |
| TC-EL-06 | 连续点两次（均成功） | 两笔 requestId、扣两次 | UC-10 AC-06 |
| TC-EL-07 | 同 requestId 重试 hold（可 Swagger） | 余额只少一次 | UC-11 |
| TC-EL-08 | hold 后生成失败或取消 | 余额恢复；流水可见退还 | UC-12 AC-07 |
| TC-EL-09 | 生成中改后台单价 | 本笔退还金额=开始快照 | UC-13 |
| TC-EL-10 | 历史任务 / 磁盘清理 | CTA 无积分后缀；不 hold | 范围 Out |

### 3.5 TTL（可选缩短 TTL）

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-TTL-01 | hold 后不 commit，等过期 | 自动退还；再 commit 失败 | Q-02 NA-10 |

---

## 4. 通过 / 失败

- **通过：** TC-ENG 全过；TC-SET / TC-ADJ / TC-LED / TC-AUTH 全过；TC-EL-01～10 全过。
- **TTL：** 实现后 TC-TTL-01 必过；未改短 TTL 时可用 e2e 注入时钟代替人工等 20 分钟。
- **失败：** 任 Must 用例失败即本需求未验收。

---

## 5. 回归

- 后台用户/角色/管理员 CRUD 仍可用
- Electron 登录、生图（mock provider）在积分为 0 的功能上仍能生成（Q-01）
- 不写积分到 `prisma-log`
