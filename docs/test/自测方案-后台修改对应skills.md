# 自测方案 · 后台修改对应 skills

> 对齐：[需求梳理版](../detail/需求-后台修改对应skills-梳理版.md)、[技术设计](../design/技术设计-后台修改对应skills.md)、[开发计划](../plan/开发计划-后台修改对应skills.md)  
> 范围：MVP（UC-01～11）  
> Nest e2e、Electron 单测与本表互补：自动化过不等于可免人工看 prompt

---

## 1. 测试范围

| 纳入 | 不纳入 |
|------|--------|
| 功能设置 skills 列、弹窗保存/清空/超长 | 文案仿写配置、按规格拆段、版本历史 |
| `skillPrompt` 读写、省略不覆盖、桌面 JWT 不能改 | 积分计价、预扣、流水、CTA 文案 |
| 灵感 / 原景出新 / 自由创作 / 裂变出图 / live 的前缀 | 裂变识图、智能裁剪、中转站协议字段 |

---

## 2. 环境与前置

| 项 | 要求 |
|----|------|
| Nest | 已 migrate；`PointFeature.skillPrompt` 可空；种子管理员可登录 |
| Admin | 功能设置页能打开现有 6 行 |
| Electron | 指向同一 Nest 的本需求包；已登录；创作页能拉到 `/point-features` |
| 观察 prompt | 桌面开发日志、历史记录里的 prompt，或 mock provider 收到的 `prompt`。三处任一即可，但同一条用例只认一处 |
| 前缀样本 | 固定一句，例如 `【SKILL】保持商品主体。`，便于在长提示词里搜索 |

**通过：** 该用例期望全部出现。**失败：** 前缀缺失、前缀重复、加错请求，或超长仍落库。失败则停在该功能，不把「其他功能正常」算作本用例通过。

---

## 3. 用例表

### 3.1 后台

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-ADM-01 | 打开功能设置 | 图片功能有 Skills 列；空为「未配置」；无历史/清理行 | UC-01 AC-01 |
| TC-ADM-02 | 灵感创作填写样本句，与单价、备注一起保存，再打开 | 列变为「已配置」；弹窗回显全文；单价备注仍在 | UC-02 AC-01 |
| TC-ADM-03 | 清空文本并保存 | 列回到「未配置」；再次打开为空 | UC-03 AC-02 |
| TC-ADM-04 | 输入 4001 字保存 | 不关闭成功态；列表仍是保存前状态 | UC-04 AC-03 |
| TC-ADM-05 | 打开文案仿写修改弹窗 | 无 skills 输入框；保存单价不把其他功能的 skills 清掉 | UC-12 AC-09 |

### 3.2 鉴权

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-AUTH-01 | 无 token PATCH `/admin/point-features/generate.create.inspire` | 401，库不变 | UC-11 AC-08 |
| TC-AUTH-02 | 桌面 JWT 调用同一 PATCH | 401，库不变 | UC-11 AC-08 |

### 3.3 桌面出图

每条开始前：后台已为对应功能保存样本句，桌面重新进入该创作页（让缓存刷新）。结束后按 TC-ADM-03 清掉，避免污染下一条。

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-EL-01 | 灵感创作点生图 | 出图 prompt 以样本句开头，后面仍是本地灵感模板 | UC-05 AC-04 |
| TC-EL-02 | 原景出新点生图 | 同上，后半是原景模板 | UC-05 AC-04 |
| TC-EL-03 | 自由创作输入「红色杯子」再生成 | 样本句在前，「红色杯子」在后；输入为空时仍提示填写，不生成 | UC-09 AC-04 |
| TC-EL-04 | 裂变走完识图再出图 | 识图请求不含样本句；批量出图请求含样本句且只出现一次 | UC-07 AC-05 |
| TC-EL-05 | 在 TC-EL-04 之后点继续或失败重试 | prompt 仍只有一个样本句 | UC-07 Q-04 |
| TC-EL-06 | live 任选一档生成 | 实况生成用的 motion prompt 以样本句开头；优/中/良不用另配一段 | UC-08 AC-06 |
| TC-EL-07 | 清空该功能 skills 后再生成一次 | prompt 不再含样本句，与改前本地模板一致 | UC-06 AC-02 |
| TC-EL-08 | 不登录或配置接口失败时点生图（可用断网点一次） | 仍按本地提示词生成或走现网失败提示，不出现「缺少 skills」 | UC-10 AC-07 |
| TC-EL-09 | 文案仿写生成 | 请求正文与本需求前一致，无样本句 | UC-12 AC-09 |

### 3.4 回归

| 用例 ID | 步骤 | 期望 | 追溯 |
|---------|------|------|------|
| TC-REG-01 | 只改灵感单价、不改 skills，保存 | 已写的样本句还在 | NU-08 |
| TC-REG-02 | 灵感 CTA、预扣失败退还各走一次 | 与积分模块现网一致 | AC-09 |
| TC-REG-03 | Nest 积分 e2e；Admin `pnpm typecheck`；Electron `prependSkillPrompt` 单测 | 通过 | 计划 T3.1 |

## 4. 通过标准

- TC-ADM-01～05、TC-AUTH-01～02、TC-EL-01～09、TC-REG-01～03 全部达到期望。
- 任一条出现双前缀、识图带前缀、超长落库，整项不通过。
