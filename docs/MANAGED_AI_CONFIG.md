# 模型服务管理（APP 直连）

管理后台左侧一级菜单 **模型服务**，路由 `/ai-config`。服务端只保存、发布和下发配置；本页不会请求模型 API。

## 使用流程

1. 添加服务，填写名称、供应商基础地址、调用协议、准确模型名称和 API Key。
2. 在功能分配中，为需要启用的处理阶段选择服务。同一服务可被多个阶段共用。
3. 保存草稿。保存并不改变已发布配置，密钥保存成功后输入清空、列表仅显示掩码。
4. 检查配置并发布。APP 下次同步后，新任务使用新配置；运行中的任务继续使用既有配置。

四类协议为 Chat Completions、Responses 生图、Images REST 生图/编辑、Wan 视频。Wan 视频的基础地址填写供应商 API 根地址，不追加 /v1。图片裂变识图、自由创作提示词优化、文案生成和 LIVE 动作提示词阶段要求图文理解服务具备识图能力。

允许只分配部分阶段。APP 处于“后台配置”模式时，未配置的阶段不能开始生成，禁用全局配置也会阻止该模式的新任务，不会暗中改用其他服务。需要回滚时在 APP 手动切回“原有配置”；原有本地密钥和老版本应保留。

## 密钥与发布规则

- 已保存密钥不可在后台回读；编辑时留空保留原密钥，输入新值即替换。
- 未保存的密钥只暂存在当前页面内存，不写 localStorage/sessionStorage。
- 草稿有未保存修改时不能直接发布；离开页面会提示丢弃未保存内容。
- 保存与发布使用 `expectedDraftRevision`，版本冲突不会覆盖其他管理员的修改。重新载入后按最新配置编辑。
- 服务器未配置密钥加密时，本页禁用保存与发布。HTTP 基础地址还需服务端显式允许。
- “检查配置”检查字段和协议匹配，不等于供应商连通性或模型可用性测试，也不产生模型调用费用。
- 替换后台 Key 不会自动撤销供应商处的旧 Key。

## 开发与验证

管理 API：`GET /admin/ai-config`、`PUT /admin/ai-config`、`POST /admin/ai-config/publish`，复用后台登录和令牌刷新。

已执行：新增逻辑 8 项测试、后台完整类型检查、生产构建、新增文件 ESLint，以及使用模拟接口的独立浏览器验收。浏览器验收覆盖添加/保存/分配/发布流程、未分配时阻止发布、保存后密钥输入为空、浏览器本地存储不含密钥。未连接生产后台或实际供应商。

项目的 `.npmrc` 使用 `shamefully-hoist=true`。如果 pnpm 11 没有沿用该设置，请安装时显式传入 `--shamefully-hoist`，或使用项目原有 pnpm 版本。此次没有修改依赖版本或锁文件。依赖已安装后可直接运行：

```powershell
.\node_modules\.bin\vue-tsc.cmd --noEmit --skipLibCheck
.\node_modules\.bin\tsx.cmd --test tests/ai-config.test.ts
.\node_modules\.bin\vite.cmd build --mode prod
```
