# 积分价格调整与发布（2026-10-25）

## 本次价格

| 功能 | 每项价格 | 批量示例 |
|---|---:|---|
| 图片生成（裂变、自由创作及其他生图入口） | 10 积分/张 | 4 张 = 40 积分 |
| 文案生成（标题和正文合为一篇） | 3 积分/篇 | 默认 3 篇 = 9 积分 |
| Live 本地镜头动效 | 1 积分/条 | 每次成功生成收 1 分 |
| Live API 动态视频 | 100 积分/条 | 优、中、良均为 100 分 |

本地 Live 在电脑上编码，但现在需要登录并连接平台完成积分预扣。失败、取消退还该项预扣积分；批量逐项结算。导出已有 Live、下载、打开网盘上传辅助不重复扣生成积分。已生成结果重做属于一次新的生成。

## 给开发者的说明

价格来源是 `PointFeatureSpec.unitPoints`，不是模型 API 密钥或服务配置。桌面端发送菜单码、规格和数量，不发送扣费金额，后台计算并保存预扣快照。

| menuCode | specKey | unitPoints |
|---|---|---:|
| `generate.create.inspire` / `fission` / `scene-renew` / `free`（均以 `generate.create.` 为前缀） | `default` | 10 |
| `generate.create.copywrite` | `default` | 3 |
| `generate.create.live` | `local`（新增） | 1 |
| `generate.create.live` | `high` / `medium` / `good`（兼容旧版） | 各 100 |

- 数据迁移 `20261025090000_generation_points_pricing` 一次性更新现有数据库价格，缺少功能或规格时补齐。保留功能自定义名称、备注和创作要求，不改用户余额和历史/进行中流水。
- `prisma/point-feature-defaults.ts` 是新安装的默认价格。重复 seed 保留管理员之后调整的价格；不要为了改价运行整套 seed（它还会处理管理员初始化）。
- 桌面端本地 Live 从免扣分改为 `specKey: local` 预扣、成功确认、失败退款。重试使用原任务模式，而不是当前页面选项。API 轮询恢复沿用已创建的视频任务 ID，避免重复提交模型任务；上次退回预扣后，恢复成功仍结算一条生成费用。
- 缺少后台价格时不再显示为 0 分，本地 Live 禁止提交并提供刷新价格入口。
- 管理后台增加本地动效单价，AI 三档初始均为 100，保存时保留服务器提供的完整规格集合；旧服务器没有 local 时不会强行发送未知规格。积分流水能够显示本地动效。
- 这是现有“客户端预扣—生成—确认/退款”机制的价格调整，没有更换生成服务路由，也没有把模型密钥写入安装包。旧版本客户端仍能跳过本地动效预扣，收费上线应统一升级客户端；不将本次改动宣称为防篡改或强制最低版本机制。

## 发布顺序

1. 选择任务空闲时段，备份数据库和当前三端版本。尤其保存当前价格，方便回滚。
2. 合并/检出 nestjs 分支并部署。容器启动脚本已有 `prisma migrate deploy`，会自动执行本次迁移。保留现有环境变量、域名、数据库和密钥，不用整机初始化部署脚本覆盖这些设置。
3. 发布 admin 分支，在后台“功能设置”核对生图 10、文案 3、Live 本地 1、AI 三档 100。
4. 分发 electron 分支编译的客户端并重启客户端以刷新价格。先确认后台含 local 规格，再给用户切新版。
5. 使用专用测试账号验收：生成 1 张扣 10，生成 3 篇共扣 9，本地 Live 扣 1，API Live 扣 100。余额不足不应启动任务；失败/取消最终应退款。API 验收会产生上游费用，按需只做一次。

### 备份与回滚价格

在 `apps/nest-api` 下，使用现有 `DATABASE_URL`（不要提交连接串）运行：

```sh
node scripts/point-prices-backup.cjs /secure-backups/point-prices-before-20261025.json
```

必须在本次迁移执行之前备份。脚本只保存六个创作功能的规格、名称和价格，不包含账户或密钥；同名文件存在时拒绝覆盖。

如果从旧版 Docker 容器备份，旧版还没有这个脚本，可先从新检出的仓库复制脚本到旧容器，然后执行并取回备份：

```sh
docker cp apps/nest-api/scripts/point-prices-backup.cjs framework-nest-api:/app/apps/nest-api/scripts/point-prices-backup.cjs
docker exec -w /app/apps/nest-api framework-nest-api node scripts/point-prices-backup.cjs /tmp/point-prices-before-20261025.json
docker cp framework-nest-api:/tmp/point-prices-before-20261025.json ./point-prices-before-20261025.json
```

备份文件应移至安全目录，不能只留在即将被替换的容器内。

回滚时，先停止接收新生成任务并等待进行中任务结算，恢复旧客户端/后台页面，然后在具有数据库连接的环境中运行：

```sh
node scripts/point-prices-backup.cjs --restore /secure-backups/point-prices-before-20261025.json
```

该操作在一个事务中恢复六项功能的原规格/价格，包括移除备份时不存在的 local 规格；不会重算流水或余额。运行后新版客户端本地 Live 会因缺少 local 价格而禁用，因此须配合客户端回滚。不要重置数据库，不要删 Prisma 迁移历史。旧代码兼容已新增的价格数据结构，恢复镜像后迁移历史保持原样。
